# PRODIGY_SD_01 – Temperature Conversion Program (Java)

## Description
This project is a Java-based temperature conversion program developed as part of the Software Development Internship at Prodigy Infotech.

The program converts temperature values between Celsius, Fahrenheit, and Kelvin based on user input.

## Features
- Accepts temperature value from the user
- Supports Celsius, Fahrenheit, and Kelvin units
- Displays converted temperature values
- Simple and easy-to-understand logic

## Technologies Used
- Java
- Scanner class

## How It Works
1. User enters a temperature value
2. User specifies the unit (C / F / K)
3. Program converts the temperature into the other two units
4. Results are displayed on the console

## Learning Outcome
- Improved understanding of Java basics
- Practiced conditional statements and switch-case
- Gained experience in user input handling
